# Clínica Alba · Web para clínica de fisioterapia

Web de demostración para una **clínica de fisioterapia** (vale igual para dentistas, psicólogos o centros de estética). La clínica es **ficticia**.

🔗 **Verla funcionando:** https://sergio-sysops.github.io/web-clinica/

## Qué incluye

- **"¿Qué te pasa?"**: el paciente toca lo que le duele (espalda, cuello, lesión deportiva, embarazo…) y la web le recomienda el tratamiento adecuado, con un botón para pedir cita directamente.
- **Tratamientos** con duración y precio.
- **Equipo** de profesionales.
- **Cita previa por WhatsApp**: tratamiento, días que le vienen bien y mañana o tarde. Al centro le llega el mensaje ya escrito.
- **Protección de datos de salud**: el formulario avisa de que no se escriban datos médicos (son datos especialmente protegidos por el RGPD).
- **Abierto / cerrado** según el horario partido real ("Cerrado · abrimos hoy a las 16:00").
- Preguntas frecuentes, cómo llegar y horario.
- Diseño tranquilo, pensado primero para el móvil, sin cookies de seguimiento.

## Cómo se actualiza

Tratamientos, síntomas, equipo, precios y horario están en un único archivo: `datos.js`.

## Tecnología

HTML, CSS y JavaScript sin frameworks. Alojamiento gratis en GitHub Pages o Cloudflare Pages.
